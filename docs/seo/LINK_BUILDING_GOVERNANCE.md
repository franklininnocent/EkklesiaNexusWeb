# Ethical link building and off-page SEO governance

**Applies to:** EkklesiaNexus marketing, digital PR, partnerships, directory listings, and any third-party references.  
**Does not replace:** Legal review, platform Terms of Service, or Google Search Essentials.

---

## 1. Purpose

Earn **editorially justified** visibility and references for the **actual** Catholic church management product—without manipulating rankings or misrepresenting relationships.

---

## 2. Prohibited tactics (never use)

- Purchased links for ranking manipulation  
- Private blog networks, link farms, automated bulk links  
- Comment/forum spam, mass unsolicited email, scrape-and-blast contact lists  
- Link exchanges whose primary purpose is SEO  
- Fake reviews, fake testimonials, fake author/org profiles  
- Hidden links, misleading sponsorship (undisclosed paid placements as “editorial”)  
- Low-quality directory blasts without editorial review  
- Mass guest posts with no independent value  
- Keyword-stuffed press releases distributed only for anchors  
- Claiming diocesan/parish endorsement without written authorization  

**Paid ads/sponsorships:** Allowed only as **transparent marketing** per platform rules—not disguised link schemes.

---

## 3. Quality criteria (accept / pursue)

| Criterion | Question |
|-----------|----------|
| Audience relevance | Does the source reach parish admins, treasurers, or IT evaluators? |
| Editorial integrity | Original, useful content; clear ownership; no obvious manipulation |
| Topical fit | Church administration, Catholic technology, or honest software evaluation |
| Reader value | Would a link help someone evaluating ChMS? |
| Authenticity | Based on real contribution, product truth, or relationship—not a transaction for PageRank |
| Risk | No spam signals, malware, or deceptive claims |

**Reject** opportunities that fail risk or authenticity checks even if DA/DR scores look high.

---

## 4. Anchor text and destinations

- Prefer **natural, descriptive** anchors (brand name, product name, page topic).  
- Avoid **campaigns** of exact-match commercial anchors.  
- Default destinations: `https://ekklesianexus.com/`, `/solutions/catholic-parishes`, `/features`, `/contact`—match the citation context.  
- Do **not** change site URLs for keyword slugs.  
- If a third party links to a wrong or non-canonical URL, request a correction only after verifying impact (see remediation §7).

---

## 5. Product and claim accuracy

All off-page copy must align with [FEATURE_VERIFICATION.md](../FEATURE_VERIFICATION.md) and [PROHIBITED_MARKETING_CLAIMS.md](../PROHIBITED_MARKETING_CLAIMS.md).

- No attendance or data-import marketing.  
- No Reconciliation certificate claims.  
- No invented customer counts, awards, certifications, or partnerships.  
- **Pricing:** Do not quote fixed subscription amounts in directories unless the platform supports **country-aware** catalog data or generic “contact for pricing” wording.

## 7. Suspicious backlinks and disavow

1. Verify the link exists on the live page (do not trust tool exports alone).  
2. Determine whether the organization **created or paid** for the link.  
3. Assess scale, pattern, and relevance.  
4. If GSC access exists, check **Manual actions** and **Links** reports.  
5. Document in earned-links register with confidence level.  

**Disavow:** Only after human review consistent with [Google’s disavow guidance](https://developers.google.com/search/docs/advanced/guidelines/consolidate-duplicate-urls) (use when there is a clear pattern of artificial links **you** control or paid for). Do not disavow routine low-quality noise. **Site owner** must approve file upload.

---

## 8. Technical prerequisite

Off-page work **does not replace** P0 technical SEO. Resolve duplicate-host serving, GSC verification file deploy, and canonical hygiene per [SEO_ISSUE_REGISTER.md](SEO_ISSUE_REGISTER.md) before scaling outreach.
